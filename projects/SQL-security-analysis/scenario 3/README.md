## Project Description
In this project I needed to retrieve information about employee machines and departments from an organization's relational database. I used SQL to select specific columns, filter records using the WHERE clause, and search for matching office patterns using the LIKE operator. The analysis focused on the machines and employees tables in a MariaDB database.

## Objectives
-Identifying organization machines and their operating systems.
-Identifying machines running OS 2.
-Identifying employees in the Finance and Sales departments.
-Identifying employees and machines associated with the South building.

## Summary
In this investigation, I used SQL to retrieve and filter information about employee machines and departments. I practiced selecting specific columns, filtering records with the WHERE clause, using exact matches with =, and searching for patterns with LIKE and %. These skills are useful for security and IT teams when identifying affected machines, locating employees, and investigating organizational data.
