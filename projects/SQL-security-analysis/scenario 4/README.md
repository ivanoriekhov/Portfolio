## Project Description
I needed to retrieve information about employee devices and analyze login activity for unusual behavior. I used SQL to select specific columns from relational database tables, retrieve complete records, and organize login activity using the ORDER BY keyword. The investigation focused on the machines and log_in_attempts tables in a MariaDB database.

## Objectives
-Retrieving employee device information. 
-Reviewing operating systems, email clients, and patch dates.
-Investigating login locations. Reviewing login dates and times. 
-Sorting login activity chronologically.

## Summary
In this project, I used SQL to retrieve information about employee machines and login activity from a relational database. I practiced selecting specific columns, retrieving complete records with *, and organizing results using ORDER BY and multi-column sorting. These skills provide a foundation for analyzing security data and identifying unusual activity in larger datasets.
