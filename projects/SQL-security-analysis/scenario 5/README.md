## Project Description
In this project, I used SQL to investigate security-related information stored in an organization's relational database. I worked with the machines, employees, and log_in_attempts tables to connect employee, machine, and login information using SQL joins.

## Objectives
-Connect machines and employees using the device_id column.
-Use LEFT JOIN to retrieve machine information and matching employees.
-Use RIGHT JOIN to retrieve employee information and matching machines.
-Connect employees with login attempts using the username column.
-Apply SQL joins to support a security investigation.

## Summary
In this investigation, I practiced using INNER JOIN, LEFT JOIN, and RIGHT JOIN to combine information from multiple database tables. These skills are useful for security and IT teams when analyzing employee activity, identifying machines, and investigating login attempts.
