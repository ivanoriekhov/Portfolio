## Project Description
I investigated login activity related to a recent security incident. I used SQL to filter login attempts by date, time, and event ID in order to narrow a large dataset down to specific records relevant to the investigation. The analysis was performed using the log_in_attempts table in a MariaDB relational database.

## Objectives
-Identify login attempts after a specific date.
-Identify login attempts within a specific date range.
-Investigate login attempts occurring during specific times.
-Investigate login attempts using specific event ID ranges.

## Summary
In this investigation, I used SQL to analyze login activity associated with a security incident. I filtered records using comparison operators and BETWEEN to investigate specific dates, times, and event ID ranges. These techniques demonstrate how SQL can be used to narrow large datasets and efficiently identify information relevant to a security investigation.
