## Project Description
As a security professional at a large organization, I investigated potential security issues involving user login activity and employee machines. I used SQL to query the organization's relational database and apply filters to identify suspicious login activity, investigate login locations, and retrieve employee information needed for security and system updates. The investigation was completed using MariaDB and focused on the log_in_attempts and employees tables.

## Objectives
The investigation focused on six security and IT-related questions:
  -Identify failed login attempts occurring after business hours.
  -Identify login attempts occurring on specific dates.
  -Identify login attempts originating outside of Mexico.
  -Identify Marketing employees located in the East building.
  -Identify employees in the Finance or Sales departments.
  -Identify employees who are not part of the Information Technology department.

## Summary
In this project, I used SQL to investigate potential security issues involving login activity and employee systems. I applied WHERE, AND, OR, NOT, and LIKE filters to analyze login attempts by time, date, and location and to identify employees based on department and office location. These queries demonstrate how SQL can be used to efficiently retrieve targeted information from relational databases during security investigations and IT operations.
